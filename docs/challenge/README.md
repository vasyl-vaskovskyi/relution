# Discovery Day challenge material

This folder holds everything that exists **only for the Relution Discovery Day** coding challenge. It is kept separate from the durable documentation ([ADR-0039](../adr/0039-documentation-structure.md)), so it can be frozen after the review and removed when the code is merged into a product.

| File | Contents |
|---|---|
| [`brief.md`](brief.md) | The task, the scope chosen for a backend position, and what reviewers look for |
| [`plan.md`](plan.md) | Working agreement for the day, kickoff checklist, schedule, cut and stretch order, smoke checks |
| [`presentation.md`](presentation.md) | Sprint-review presentation checklist and honest-assessment notes |
| [`ai-log.md`](ai-log.md) | AI suggestions that were rejected, corrected or reworked (evidence for the review) |

Personal names are used here on purpose, because this material documents who decided what during the challenge. Durable docs use roles.
